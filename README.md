# VisaBook

Настоящие брони авиабилетов (hold, без оплаты) и отелей (с бесплатной отменой) для визового центра + PDF на почту.

## Запуск
1. Зарегистрируйтесь на https://app.duffel.com, возьмите токен (Developers → Access tokens).
2. Вставьте его в `.env` → `DUFFEL_TOKEN=...` (и SMTP, если нужны письма).
3. `npm start` → http://localhost:3000

Тестовый токен (`duffel_test_...`) — фейковая авиакомпания "Duffel Airways", ничего не списывается.
Боевой (`duffel_live_...`) — настоящие брони. Отели (Duffel Stays) нужно отдельно активировать в аккаунте Duffel.
